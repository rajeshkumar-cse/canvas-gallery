# 🎨 The Canvas Fable

A curated online art gallery showcasing paintings, sketches, and original artworks.

**Live Site:** [thecanvasfable.com](https://thecanvasfable.com)

## Tech Stack

- **Framework:** Next.js 15 (Static Export)
- **Styling:** Tailwind CSS 4
- **UI Components:** shadcn/ui
- **Hosting:** GitHub Pages
- **CI/CD:** GitHub Actions

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the gallery locally.

## Adding Artwork

1. Place your images in the `public/images/` folder
2. Update `src/data/artworkData.ts` with the image paths and titles
3. Commit and push — the site deploys automatically

## Build

```bash
npm run build
```

Static output is generated in the `out/` directory.
